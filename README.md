# Budget Tracker Visual Design

This project is a polished budget tracker landing page designed to match the visual identity brief for the weekly assignment. The layout focuses on a clean, professional look with a cohesive palette, custom typography, styled form fields, and a carefully formatted expense table.

## Files

- `index.html` – Contains the page structure, including the page header, expense form, and expense table.
- `style.css` – Handles the full visual design, including colors, fonts, layout spacing, table styling, and responsive behavior.

## What the design includes

- A consistent teal-and-gold color palette for a modern budgeting feel
- Google Fonts for stronger typography and visual hierarchy
- Distinct card-based sections for the heading, form, and table
- Rounded corners, borders, shadows, and spacing created through the CSS box model
- A clear expense table with alternating row colors and styled headers
- A responsive layout that keeps the interface easy to read on smaller screens

## How to view it

Open `index.html` in a browser to see the page.
